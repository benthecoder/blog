til:
- ARIA = accessible rich internet applications. a set of HTML attributes (`aria-*`, plus `role`) that describe UI semantics to assistive tech like screen readers, voice control, and braille displays. browsers don't render ARIA visually; it only changes what gets announced to people who can't see the screen
- common ones
  - `aria-hidden="true"`: hide this from screen readers (still visible on screen)
  - `aria-label="..."`: a label for an element with no visible text, like icon buttons
  - `role="meter"`: treat this div as a meter, which is why a slider can have `role="meter"` with `aria-valuenow`
  - `aria-valuenow`/`min`/`max`: the numeric value for sliders and meters
