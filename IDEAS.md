# Ideas

Possible additions to the site, not a committed roadmap. Developer commands are in [README.md](README.md).

## Photos

- **photos.bneo.xyz**: a chronological photostream and photosets grouped into trip collections, inspired by [Paul Stamatiou's photos](https://paulstamatiou.com/photos). Collections show photos taken, days and km, with day-by-day sets linking to journal posts. Use the photos in R2; the existing `/gallery` is the starting point.

## Reading interactions

- **Expanding text**: reveal an aside inside the sentence without leaving the page. [Spencer Chang](https://spencer.place/) uses clickable asterisks to expand extra text inline.
- **Popup notes**: open a note in a separate panel while keeping the original text visible. [Rishi Kothari](https://www.rishi.cx/) opens panels from words such as “Rishi” and “hack”. This is distinct from the existing internal-post hover previews.
- **Expanding sidebar**: explore a sidebar that reveals more navigation on interaction, inspired by [Linus Rogge](https://linusrogge.com/about).
- **Breadcrumb navigation**: show the path through nested wiki categories. The old Jake reference now redirects to [jake.kitchen](https://jake.kitchen/), which no longer demonstrates the navigation.

## Reading updates

- **Currently reading**: show the current book and recent reading updates alongside the existing Spotify listening updates on `/now`. The existing `/library` already lists books; this idea is a current-status view.

## Performance and discovery

- **Measure before improving**: revisit image loading, `/thoughts` performance and SEO only with a specific gap or measured regression. Responsive lazy-loaded images, image caching, paginated cached thoughts, metadata and a sitemap already exist. [The Featherweight Website](https://macwright.com/2016/05/03/the-featherweight-website) is a reference for keeping page weight low.
